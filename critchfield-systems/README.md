# Critchfield Systems website

Static site for CritchfieldSystems.com: plain HTML, CSS and JS, no build step needed to host it.
Generated by `_tools/build-critchfield-systems.py` from sections in `DeveloperDadd/components`.

## Cloudflare Pages

- Framework preset: **None**
- Build command: *(leave empty)*
- Build output directory: **`critchfield-systems`**

## Edit and rebuild

Phone number, email and all copy live in `_tools/build-critchfield-systems.py`
(`PHONE_DISPLAY`, `PHONE_E164`, `EMAIL` at the top). Then:

    python3 _tools/build-critchfield-systems.py /path/to/components

"Keystone Ridge Roofing", served at critchfieldsystems.com/sample/. It is built by

Photos are the placeholder photos that ship with the components (CodeStitch image CDN),
listed in the `IMG` table at the top of the build script. Pages are `noindex` and the phone
number is Critchfield Systems' own (859) 270-7050. There are no forms: every button is the same `.cs-button-4` "Call Now"
button linking to the phone number (the build enforces this).
